# Тестовое задание: постобработка OCR паспорта РФ

Срок 3 дня. ИИ можно.

## Задача

Модель распознала паспорта РФ: в `data/*_predictions.jsonl` лежит то, что она прочитала. Нужно по каждому документу решить: **принять** (и выдать значения полей) или **отклонить** (попросить переснять).

Принятый документ с ошибкой обходится нам намного дороже, чем отклонённый. Нужно принять как можно больше документов и при этом не принять ни одного с ошибкой.

Документ принят верно, если все 10 полей совпадают с разметкой и паспорт действителен на 01.10.2026.

## Данные

| Файл | Что внутри |
|---|---|
| `data/train_predictions.jsonl` | 3000 документов: вывод модели |
| `data/train_labels.jsonl` | разметка к train |
| `data/test_predictions.jsonl` | 2000 документов без разметки, по ним мы считаем результат |
| `reference/subdivisions.csv` | справочник кодов подразделений (DaData, CC BY-SA 4.0) |
| `evaluate.py` | сверка ответов с разметкой: `python evaluate.py answers.jsonl data/train_labels.jsonl` (действительность паспорта не проверяет) |

Одна строка `*_predictions.jsonl` — один документ:

```
doc_id     id документа
source     откуда снимок: web / mobile / mobile_v2
quality    sharpness, doc_px, glare — метрики снимка
viz        10 полей визуальной зоны; поле = null, если детектор его не нашёл
  box        рамка поля [x, y, w, h]
  conf       средняя уверенность по полю
  lines      прочитанные строки: text, box, char_conf (уверенность по каждому символу)
mrz        машиночитаемая зона (null, если не найдена)
  lines      строки: text, char_conf
```

Поля и формат значений — как в `train_labels.jsonl`.

## Что сдать

Ссылку на репозиторий, в котором есть:

1. **Код:** `python postprocess.py data/test_predictions.jsonl answers.jsonl`. Работает на CPU, без интернета.
2. **`answers.jsonl` для test.** Одна строка на документ: `{"doc_id": "...", "decision": "accept" | "reject", "fields": {...}}`. Поля нужны только у принятых.
3. **Отчёт (до 2 страниц)** о том, что ты сделал и что выяснил. Что в него включить, решай сам. Обязательно только одно: прогноз, сколько документов test ты примешь и сколько из них окажутся с ошибкой.
