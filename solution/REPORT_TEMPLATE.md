# Отчёт: постобработка OCR-паспортов

## Задача и данные

Для каждого результата OCR нужно решить, принять документ или отклонить его для повторного снимка. Ошибка в любом из 10 полей делает принятие неверным. В проекте есть 3000 размеченных train-документов и 2000 test-документов без разметки. Доступны текст OCR, оценки уверенности и качества снимка, MRZ и справочник кодов подразделений; самих изображений нет.

## Реализация

В `solution/postprocess.py` находится единый скрипт обучения и применения модели. В обычном режиме он загружает готовую модель `solution/calibrator.json` и запускается так:

```bash
python3 solution/postprocess.py data/test_predictions.jsonl solution/answers.jsonl
```

Нейросеть предсказывает правильность каждого OCR-поля. В признаки входят уверенности поля и символов, длины и форматы распознанных значений, метрики снимка, источник данных, признаки согласованности с MRZ и сверка названия подразделения с вариантами для распознанного кода. Отдельный калибратор сопоставляет `char_conf` символов с вероятностью символьной ошибки, используя выравнивание OCR-текста с `train_labels`. Символьные риски объединяются в оценку риска ошибки документа; порог этой оценки и порог нейросети подбираются совместно на calibration.

Решение дополнительно проходит детерминированные проверки: наличие и формат полей, порядок и допустимость дат, срок действия по реализованным правилам, согласованность даты рождения и пола с MRZ, наличие кода подразделения в `reference/subdivisions.csv` и сходство названия с вариантами для этого кода. Для обычного применения готовой модели PyTorch не требуется; он нужен только для обучения.

## Обучение и оценка

Обучение запускается командой `python3 solution/postprocess.py --train`. При фиксированном seed 417 данные делятся на fit (1800 записей), calibration (600) и holdout validation (600). Нейросеть и калибратор символьного риска обучаются на fit. На calibration совместно выбираются пороги модели и символьного риска с целевой точностью 100% на calibration; holdout остаётся отдельной проверкой.

В последнем запуске на calibration принято 71 из 600 документов без ошибок. На holdout принято 77 документов, из них 3 с ошибкой. Эти результаты показывают, что нулевая ошибка на calibration не гарантирует нулевую ошибку на независимой выборке.

## Результат и прогноз для test

В последнем сформированном `solution/answers.jsonl` принято **240 из 2000** test-документов и отклонено **1760**.

## Файлы результата и ограничения

- `solution/answers.jsonl` — одна запись на каждый test-документ; у принятых записей включены все 10 полей.
- `solution/rejected_records.jsonl` — отказы с причинами, оценками и распознанными полями; на test эталонные значения неизвестны.
- `solution/holdout_false_accepts.jsonl` — ошибочно принятые записи holdout с ожидаемыми и предсказанными полями для анализа.
- `solution/calibrator.json` — веса сети, перечень признаков, параметры стандартизации и порог.

Нейросеть и символьный калибратор оценивают риск по небольшому обучающему набору и не могут надёжно обнаружить каждую словарную ошибку OCR, если модель присвоила ошибочным символам высокую уверенность. Сверка названий с неполным справочником также не заменяет проверку изображения. `evaluate.py` проверяет совпадение полей, но не валидность паспорта; фактические ошибки test без разметки неизвестны.
